## 关键前提

| 维度 | 决策 |
| --- | --- |
| 技术栈 | Go 作核心基座，重 AI 能力（嵌入/重排/OCR）一律走外部 API |
| 使用范围 | 单用户、本地运行。不做多租户、计费、运营后台 |
| 产品矩阵 | 内核一次性投入，之后 Web / 桌面 / CLI / Bot 是并列产品（[ADR-0019](./adr/ADR-0019-形态路线改为产品矩阵.md)） |
| 模型接入 | OpenAI 兼容 + Responses + Anthropic 原生；本地模型按兼容协议接入 |
| 模型网关 | 任意 OpenAI 兼容、Responses 或 Anthropic 端点。作者本地使用的网关是 ModSwitch（三种协议共用 `/v1`，`/v1/models` 列模型），非必需 |

## 快速开始

```bash
# 1. 设置模型网关的密钥
export ANTHROPIC_AUTH_TOKEN="your-key"

# 2. 复制配置
mkdir -p "$APPDATA/baiyi"
cp configs/config.example.toml "$APPDATA/baiyi/config.toml"

# 3. 构建并运行
make build
./bin/baiyi.exe
```

## 当前能力

- **对话**：三种协议流式、思考过程、跨进程续聊、编辑与重新生成（分支不改旧消息）
- **工具**：`time_now` / `tool_output_read` / `ask_user` / `load_skill` /
  `rag_search` / `rag_list_documents` / `memory_write` / `memory_search`，
  外加任意 MCP server 的工具
- **Agent**：八态状态机、并行工具调用、步数/墙钟/预算、中断续跑
- **审批**：三级风险、终端 y/n、污点追踪
- **上下文**：八段分层、严格降级链、逐段快照、稳定前缀保护
- **技能**：目录即生效、渐进披露、确定性触发
- **知识库**：md/html/txt 接入、结构化切分、向量+关键词混合检索（RRF）、
  重排降级、可定位引用、四种嵌入后端、持久任务队列
- **记忆**：规则抽取、四态合并（新增/确认/更新/冲突）、画像卡注入稳定前缀、
  情节线索召回、可撤销可溯源、外部内容三层隔离
- **降级**：Provider 失败自动切次选；嵌入服务不可用时检索退为纯关键词；
  记忆召回失败静默跳过
- **Web**：技能与插件在界面里启停并热生效；会话可导出 Markdown / JSONL，
  数据库可一键备份；上下文检查器能看每一段的 token、配额和裁剪原因；
  记忆与知识库可在界面里查看、确认和删除
