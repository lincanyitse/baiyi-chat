## Context

M0–M2 把内核做完了：能对话、调工具、有记忆、能检索文档。但**唯一的入口是一个调试用的 REPL**——终端里 `./baiyi.exe`，输出是纯文本，看不了引用跳转、点不了审批按钮、翻不了历史。

M3 把这些能力搬进浏览器：HTTP API + SSE 流式、会话列表与分支树、审批弹窗、Provider/记忆/知识库管理页、成本面板、上下文检查器。

**这不是「加个前端」**。探查发现内核缺了几块 Web 必需的能力：没有 per-turn 取消、没有会话删除/归档、`parent_id` 从未使用、成本只有按会话聚合、配置不能写回。M3 必须先把这些补到内核，再谈界面。

### 已确认的决策

| 维度 | 决策 | 理由 |
| --- | --- | --- |
| 前端 | **Svelte 5 + Vite**，`npm run build` → `go:embed` 到二进制 | 编译期框架产物小、无运行时；单二进制分发 |
| 拆分 | **M3.1 核心对话 → M3.2 管理界面** | 先让「能聊天」跑通并验证 SSE，再补其余 |
| 会话分支 | **完整分支树** | `parent_id` 已在表里，一次做对，避免后续迁移历史数据 |
| 本地口令 | **做**，`golang.org/x/crypto` Argon2id | 官方扩展库；自写 PBKDF2 是安全风险 |
| 监听地址 | **可配置，默认 `127.0.0.1:8787`** | 改成 `0.0.0.0` 时启动警告 |
| 前端产物 | **`dist` 不进 git** | `make web` 构建；源码进 git |
| M3.1 工具集 | **限定只读工具** | 避开通审批，从源头避免「模型调了工具却卡在审批」的死局 |
| M3.2 工具集 | **放开全部**，审批弹窗就绪 | 白名单机制保留，作为「只读助手」的显式开关 |

### 边界规则

- `channel/web` 与 `channel/repl` **平级**，都只依赖 `session.Service` 与少数窄接口；两者**不互相 import**
- `web` 不得 import `provider/*` 适配器——需要 Provider 能力时经 `session.Service` 或 `registry.Registry` 的窄接口
- DTO 与内部类型分开：`session.TurnResult` 有 `time.Duration` 字段，直接序列化会变成纳秒整数
- 前端产物通过 `go:embed` 嵌入，但 `dist` 与 `node_modules` 进 `.gitignore`

## 关键设计决策

### 1. SSE 断线重连补发：内存环形缓冲 + 单调事件 ID

`StreamCallback` 是**一次性**的：agent 在单 goroutine 里同步调用，事件不重放。要支持「断开重连按序补发」，必须在渠道层缓冲。

`stream.Log` 是单写多读的环形缓冲（单轮 20000 条 / 8 MiB），`Append` 永不阻塞订阅者——卡住的浏览器不能拖慢模型输出。

- 每个事件带 `id: <seq>`，重连时从 `Last-Event-ID` 之后重放
- 超出缓冲时丢弃最早的并给订阅者一个 `reset` 信号，前端据此重拉消息树
- 心跳每 15 秒一条 `: ping` 注释行，不占序号
- **不落库**：每个 delta 写一次 SQLite 会击穿 `NFR-PERF-002` 的 50ms 排队要求

缓冲放在 `channel/web` 而不是 `session`：REPL 不需要重放。

### 2. 停止生成：按 turn 注册 cancel，放在 session 层

```go
type turnHandle struct {
    cancel  context.CancelFunc  // nil 表示已预占但未开跑
    stopped bool
}
```

`reserve` 先占位，`begin` 拿到 ctx 后填进去。用结构体而不是装空函数，是为了区分「还没开始」与「已开始且可取消」。

放在 `session` 而不是 `web`：REPL 的 Ctrl-C 也该只停当前轮。

### 3. 分支树：`parent_id` 建树，叶子节点决定视图

数据模型不改表（`parent_id` 从 M0 就在）：

```
user1 ← parent = NULL
  └ asst1a ← parent = user1
      └ user2 ← parent = asst1a
  └ asst1b ← parent = user1     ← 重新生成产生
```

- **读取**：`HistoryAt(sessionID, leaf)` 从 leaf 沿 `parent_id` 回溯到根再反转
- **重新生成**：新回答挂到原回答的父节点下，提问不重复落库
- **编辑消息**：新提问挂到原消息的父节点下，成为兄弟
- **迁移**：`0007` 把历史消息按 seq 回填成链（M0–M2 数据 `parent_id` 全 NULL，语义上本就是单链）

### 4. 跨请求审批：内存挂起表

agent 在后台 goroutine 里阻塞等确认，用户点按钮是全新的 HTTP 请求，两者之间没有共享调用栈。

```go
type ApprovalBroker struct {
    pending  map[string]*pendingApproval  // id -> {req, ch}
    notify   chan struct{}                // 新审批出现时唤醒 SSE
    approved map[string]bool              // 本会话已放行的工具
}
```

超时与 ctx 取消都转成 `Deny`，**绝不默认放行**。危险工具不享受会话授权——不可逆操作不该因「上次点过允许」就自动执行。

不落库：单用户本地场景「重启即重开」可接受。

### 5. 口令：Argon2id + HttpOnly Cookie

威胁模型是「同一台机器上的其他人打开浏览器」，不是远程攻击者。

- Argon2id（`m=64MiB, t=1, p=4`），存 PHC 格式，参数随哈希一起存
- 登录签发 32 字节随机 token，存内存 + `HttpOnly; SameSite=Strict` Cookie，7 天有效
- 同时支持 `Authorization: Bearer`（脚本用）
- 不做 CSRF token：`SameSite=Strict` 已阻断跨站携带
- 忘记口令用 `baiyi reset-password`

**关键陷阱**：「是否启用口令」必须在**每次请求**判断。第一版放在构造中间件时判断，而口令是运行期设置的，导致中间件成了永久空壳。

### 6. 配置写回：外科手术式替换

不整份序列化——那会抹掉所有注释，且漏一个字段就静默丢失配置。

`config.SaveProviders` 按行扫描删掉 `[providers.*]` 与 `[route.*]` 段，把新段渲染后插回原位置，其余字节原样保留。渲染后先交给 TOML 解析器自检语法，通过才写临时文件再 `rename`。

### 7. 前端：Vite + 手写路由，不用 SvelteKit

单用户 SPA 用不上 SSR/多页，SvelteKit 还会引入 Node 服务端。状态用 Svelte 5 原生 runes，不引状态库。

## 测试策略

| 目标 | 手段 |
| --- | --- |
| SSE 重连补发 | 读 3 个事件后断开 → 带 `Last-Event-ID` 重连 → 断言无重复无遗漏 |
| 停止生成 | 慢速 fake Provider → `POST /stop` → 断言 1s 内结束、状态 `canceled`、已产出内容已落库 |
| 分支树 | 建 3 条分支 → 断言 `HistoryAt(leaf=A)` 与 `(leaf=B)` 返回不同链且共享前缀 |
| 审批跨请求 | stub 发起 → `GET /pending` 可见 → `POST` 决定 → 断言 agent 拿到正确 Decision |
| 口令 | 未登录 401；错误口令不下发 Cookie；伪造 Cookie 被拒；**设置口令后立即生效** |
| 成本聚合 | 造跨多天 `llm_calls` → 断言 today/week/month 数字正确 |
| 配置写回 | 写回后其他段逐字保留；语法错不落盘；热重载后新 Provider 可用 |
| 前端 | 不写单测，Chrome DevTools MCP 手工走一遍并截图 |

## 风险与预案

| 风险 | 早期信号 | 预案 |
| --- | --- | --- |
| Svelte 构建链成为发布阻塞 | CI 里 `npm ci` 失败 | `make build-go` 跳过前端；静态资源可独立更新 |
| SSE 在反代下被缓冲 | 事件成批到达 | `X-Accel-Buffering: no`、`Cache-Control: no-cache`、15s ping |
| 分支树让 `History` 变慢 | 长会话每轮 O(n) | 缓存键含 leafID；单会话消息数 <5000 可接受 |
| 热重载中断进行中的轮次 | 「切换模型后当前回答断了」 | `AskWith` 开头取 Provider 快照，天然隔离 |
| 口令误锁 | 用户忘记口令 | `baiyi reset-password` 子命令 |
