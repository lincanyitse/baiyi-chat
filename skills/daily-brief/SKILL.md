# 今日简报流程

当用户要求生成简报时，按以下步骤执行：

1. **查时间**：调用 `time_now` 获取当前日期与时间，不要凭记忆回答。
2. **组织内容**：按「日期 → 时间 → 提醒」的顺序组织。
3. **输出格式**：

```
## 今日简报
- 日期：<年月日 星期>
- 时间：<时分>
- 提示：<一句相关的温馨提示>
```

## 约束

- 不要编造用户没有提供的待办事项。
- 如果用户之前提到过计划，可以引用；否则只报时间。
- 保持简洁，不超过 5 行。
